# Mixの並べ替え・削除

曲一覧の右上にある「編集」を押してください。各行の右端のハンドルを上下にドラッグすると順番を変更でき、その左の削除ボタンで1曲ずつ消せます。「完了」で通常の一覧に戻ります。編集中は行のタップ再生を無効にしますが、下部の操作バーは使えます。曲の読み込み・キュー更新中は編集ボタンを一時的に無効にします。

- 並べ替えても再生中の曲・経過時間・一時停止状態を維持し、次から新しい順序で再生します。再生中の音源を読み込み直しません。
- 再生中の曲を削除すると、削除前の一覧でその次だった曲へ進みます。次がなければ停止します。一時停止中なら次曲も一時停止状態です。
- 「元に戻す」で直前の削除を元の位置へ戻せます。他の編集で曲数が変わった場合は、元の位置を現在の曲数内に収めて戻します。取り消しは現在の再生を巻き戻したり、自動再生したりしません。
- 削除した曲は、同じMixの追加取得で返されても再挿入しません。すでに開始していた追加取得も、空にした一覧を再び埋めません。
- 編集は今のMixにだけ適用されます。Mixの再取得に成功した場合、API設定を変更した場合、アプリを再起動した場合はリセットします。再取得に失敗したときは編集済みの一覧を残します。再取得を開始した後は、以前の削除の取り消しは無効です。
- YouTube側の再生リストを変更する処理や、新しいサーバーAPIは追加していません。Mixの曲が変わったときのYouTubeページ追従も従来どおりです。

取得済み一覧とは別に単曲・直接URLを再生している場合、その再生には一覧編集の影響を与えません。編集結果を端末に保存する機能や、複数曲の一括削除は今回の対象外です。
